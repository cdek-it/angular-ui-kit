# ExtraScrollPanel

> ✅ **Реализован**: `ExtraScrollPanelComponent` (`@cdek-it/angular-ui-kit`) соответствует спецификации.

Контейнер с кастомным скроллбаром для прокрутки содержимого.

| Свойство | Описание                                                   | Типизация |
| -------- | ---------------------------------------------------------- | --------- |
| `height` | высота области прокрутки (CSS-значение)                    | `string`  |
| `width`  | ширина области прокрутки (CSS-значение)                    | `string`  |
| `step`   | шаг прокрутки при нажатии клавиш со стрелками (в пикселях) | `number`  |

# Слоты (content projection)

| Слот      | Описание                  |
| --------- | ------------------------- |
| `content` | прокручиваемое содержимое |
