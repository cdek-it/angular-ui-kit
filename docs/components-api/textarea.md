# ExtraTextarea

> ✅ **Реализован**: `ExtraTextareaComponent` (`@cdek-it/angular-ui-kit`) соответствует спецификации.

| Свойство         | Описание                                                                      | Типизация                          | По умолчанию |
| ---------------- | ----------------------------------------------------------------------------- | ---------------------------------- | ------------ |
| `placeholder`    | текст подсказки внутри поля                                                   | `string`                           | `''`         |
| `label`          | текст названия поля                                                           | `string`                           | `''`         |
| `labelPosition`  | положение лейбла                                                              | `top \| left`                      | `top`        |
| `floatLabel`     | лейбл-плейсхолдер, всплывающий над полем при фокусе/значении                  | `boolean`                          | `false`      |
| `clearable`      | отображение иконки для очистки поля                                           | `boolean`                          | `false`      |
| `resizable`      | разрешить изменение размера поля перетаскиванием (нативный resize-уголок)     | `boolean`                          | `true`       |
| `caption`        | текст пояснения под полем                                                     | `string`                           | `''`         |
| `info`           | текст с доп. информацией (показывается в тултипе иконки ti-info-circle)       | `string`                           | `''`         |
| `size`           | размер поля                                                                   | `small \| base \| large \| xlarge` | `base`       |
| `fluid`          | растягивает поле на всю ширину контейнера                                     | `boolean`                          | `false`      |
| `autoResize`     | автоподстройка высоты поля под содержимое при вводе                           | `boolean`                          | `false`      |
| `rows`           | стартовая высота поля в строках                                               | `number`                           | `3`          |
| `cols`           | ширина поля в символах                                                        | `number`                           | —            |
| `autofocus`      | автофокус при монтировании компонента                                         | `boolean`                          | `false`      |
| `readonly`       | только для чтения                                                             | `boolean`                          | `false`      |
| `required`       | поле обязательно для заполнения                                               | `boolean`                          | `false`      |
| `name`           | имя поля (нативный атрибут `name`); используется браузером для автозаполнения | `string`                           | —            |
| `autocomplete`   | значение нативного атрибута `autocomplete`                                    | `string`                           | —            |
| `maxLength`      | максимальное количество символов                                              | `number`                           | —            |
| `ariaLabel`      | метка для программ экранного доступа                                          | `string`                           | —            |
| `ariaLabelledBy` | `id` внешнего элемента-метки для доступности                                  | `string`                           | —            |
| `tabindex`       | порядок перехода по Tab                                                       | `number`                           | —            |

`labelPosition`/`floatLabel` — раздельные пропы (не тройной enum `left \| top \| float`, как было в
черновике спеки): `labelPosition` отвечает только за top/left, `floatLabel` — отдельный независимый
переключатель поверх любого из них (см. `docs/naming-rules.md`, раздел «Позиции»). При
`floatLabel=true` значение `labelPosition` для позиционирования самого лейбла не используется —
лейбл всегда всплывает поверх поля.

`resizable` — исправленное по `docs/naming-rules.md` имя (булево «возможность действия» → суффикс
`*able`, в черновике спеки было `resize`).

`size`/`fluid`/`autoResize`/`rows`/`cols`/`autofocus` — полезные пропы сверх первоначального
черновика спеки, уже реализованы и добавлены сюда по итогам доработки (см. чеклист в корневом
`CLAUDE.md`, п.3).

# Стекозависимые пропсы

| Описание      | Angular                                         | Vue          | React   | Типизация | По умолчанию |
| ------------- | ----------------------------------------------- | ------------ | ------- | --------- | ------------ |
| значение поля | `ngModel` \| `formControl` \| `formControlName` | `modelValue` | `value` | `string`  | `''`         |

## События

| Событие  | Описание                                                | Типизация                                   |
| -------- | ------------------------------------------------------- | ------------------------------------------- |
| `resize` | срабатывает при изменении высоты поля пользователем     | `(event: ExtraTextareaResizeEvent) => void` |
| `clear`  | срабатывает при нажатии на иконку очистки (`clearable`) | `() => void`                                |
