# ExtraSelect

> ✅ **Реализован**: `ExtraSelectComponent` (`@cdek-it/angular-ui-kit`) соответствует спецификации.

Single-select: выбор одного значения из списка. У опций нет чекбоксов (множественный выбор с чекбоксами — это `ExtraMultiSelect`).

| Свойство              | Описание                                                                | Типизация                                            |
| --------------------- | ----------------------------------------------------------------------- | ---------------------------------------------------- |
| `placeholder`         | текст подсказки внутри поля                                             | `string`                                             |
| `label`               | текст названия поля                                                     | `string`                                             |
| `labelPosition`       | положение лейбла                                                        | `left \| top \| float`                               |
| `options`             | список элементов или список групп с элементами                          | `ExtraSelectGroup[] \| ExtraSelectOption[] \| any[]` |
| `optionLabel`         | наименование поля, содержащего отображаемое значение                    | `string`                                             |
| `optionValue`         | наименование поля, значение которого используется как значение модели  | `string`                                             |
| `optionDisabled`      | наименование булева поля опции, отключающего её выбор                  | `string`                                             |
| `group`               | включает группировку опций (данные — `ExtraSelectGroup[]`)             | `boolean`                                            |
| `clearable`           | отображение иконки для очистки поля                                     | `boolean`                                            |
| `showCheckbox`        | отображать отметку выбранного option                                    | `boolean`                                            |
| `showFilter`          | показывает строку поиска в выпадающем списке                           | `boolean`                                            |
| `editable`            | разрешает ручной ввод произвольного значения в поле                    | `boolean`                                            |
| `readonly`            | только для чтения                                                       | `boolean`                                            |
| `loading`             | состояние загрузки опций                                                | `boolean`                                            |
| `caption`             | текст пояснения под полем                                               | `string`                                             |
| `info`                | текст с доп. информацией (показывается в тултипе иконки ti-info-circle) | `string`                                             |
| `size`                | размер поля                                                             | `small \| base \| large \| xlarge`                   |
| `emptyMessage`        | сообщение при пустом списке опций                                       | `string`                                             |
| `emptyFilterMessage`  | сообщение при отсутствии результатов фильтрации                        | `string`                                             |
| `inputId`             | `id` нативного инпута — для связи с внешним `<label for="...">`        | `string`                                             |
| `appendTo`            | контейнер для отрисовки выпадающей панели                              | `any`                                                |
| `checkmarkIcon`       | код символа иконки отметки выбранного пункта (при `showCheckbox`)      | `string`                                             |

# События

| Событие    | Описание                             | Типизация                                 |
| ---------- | ------------------------------------- | ----------------------------------------- |
| `change` | срабатывает при выборе значения       | `(event: ExtraSelectChangeEvent) => void` |
| `show`   | срабатывает при открытии списка       | `() => void`                              |
| `hide`   | срабатывает при закрытии списка       | `() => void`                              |
| `clear`  | срабатывает при очистке значения      | `() => void`                              |
| `filter` | срабатывает при вводе в строку поиска | `(event: ExtraSelectFilterEvent) => void` |
| `focus`  | срабатывает при получении фокуса      | `(event: Event) => void`                  |
| `blur`   | срабатывает при потере фокуса         | `(event: Event) => void`                  |

# ExtraSelectChangeEvent

| Свойство        | Описание           | Типизация |
| --------------- | ------------------ | --------- |
| `value`         | выбранное значение | `any`     |
| `originalEvent` | исходное событие   | `Event`   |

# ExtraSelectFilterEvent

| Свойство        | Описание               | Типизация |
| --------------- | ---------------------- | --------- |
| `filter`        | введённая строка поиска | `string`  |
| `originalEvent` | исходное событие        | `Event`   |

# ExtraSelectOption

| Свойство | Описание       | Типизация          |
| -------- | -------------- | ------------------ |
| `name`   | текст элемента | `string`           |
| `code`   | идентификатор  | `string \| number` |

# ExtraSelectGroup

| Свойство  | Описание            | Типизация                      |
| --------- | ------------------- | ------------------------------ |
| `options` | список элементов    | `ExtraSelectOption[] \| any[]` |
| `name`    | наименование группы | `string`                       |
