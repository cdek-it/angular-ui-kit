# ExtraStepper

> ✅ **Реализован**: `ExtraStepperComponent` + `ExtraStepperItemComponent` (`@cdek-it/angular-ui-kit`) соответствуют спецификации.

Мастер пошаговых действий. Шаги передаются как дочерние элементы `ExtraStepperItem`; активный шаг управляется через привязку значения.

| Свойство      | Описание                                                               | Типизация                | По умолчанию |
| ------------- | ---------------------------------------------------------------------- | ------------------------ | ------------ |
| `orientation` | ориентация шагов                                                       | `horizontal \| vertical` | `horizontal` |
| `line`        | отображение соединительной линии                                       | `boolean`                | `true`       |
| `value`       | значение активного шага (1-based индекс по порядку `ExtraStepperItem`) | `number`                 | `1`          |
| `linear`      | запрещает переход к шагу без завершения текущего                       | `boolean`                | `false`      |

# События

| Событие       | Описание                                | Типизация                              |
| ------------- | --------------------------------------- | -------------------------------------- |
| `valueChange` | срабатывает при переходе к другому шагу | `(value: number \| undefined) => void` |

# ExtraStepperItem

Отдельный шаг: индикатор (номер или иконка) + подпись

| Свойство   | Описание                                | Типизация           | По умолчанию     |
| ---------- | --------------------------------------- | ------------------- | ---------------- |
| `name`     | название шага                           | `string`            | — (обязательное) |
| `caption`  | подсказка шага                          | `string`            | `''`             |
| `state`    | состояние шага; не задано — обычный шаг | `success \| danger` | —                |
| `showIcon` | иконка стрелки вместо номера шага       | `boolean`           | `false`          |
| `disabled` | шаг недоступен                          | `boolean`           | `false`          |
