# ExtraStepper

Мастер пошаговых действий. Шаги передаются как дочерние элементы `ExtraStepperItem`; активный шаг управляется через привязку значения.

| Свойство      | Описание                         | Типизация                |
| ------------- | -------------------------------- | ------------------------ |
| `orientation` | ориентация шагов                 | `horizontal \| vertical` |
| `line`        | отображение соединительной линии | `boolean`                |

# ExtraStepperItem

Отдельный шаг: индикатор (номер или иконка) + подпись

| Свойство   | Описание                          | Типизация                      |
| ---------- | --------------------------------- | ------------------------------ |
| `name`     | название шага                     | `string`                       |
| `caption`  | подсказка шага                    | `string`                       |
| `state`    | состояние шага                    | `default \| success \| danger` |
| `icon`     | иконка стрелки вместо номера шага | `boolean`                      |
| `disabled` | шаг недоступен                    | `boolean`                      |
