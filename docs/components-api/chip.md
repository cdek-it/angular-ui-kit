# ExtraChip

Метка для представления значения.

| Свойство    | Описание                 | Типизация |
| ----------- | ------------------------ | --------- |
| `label`     | текст метки              | `string`  |
| `icon`      | класс иконки tabler icon | `string`  |
| `removable` | кнопка удаления метки    | `boolean` |
| `disabled`  | блокаровка               | `boolean` |

# События

| Событие    | Описание                 | Типизация    |
| ---------- | ------------------------ | ------------ |
| `onRemove` | срабатывает при удалении | `() => void` |
