# ExtraMenu

> ✅ **Реализован**: `ExtraMenuComponent` (`@cdek-it/angular-ui-kit`) соответствует спецификации.

Панель со списком пунктов: действия или навигация. Используется как самостоятельный элемент или как
всплывающее меню у триггера (`popup`).

Не используется для постоянной навигации по разделам (`Menubar`, `Tabs`) и для единичного действия
(`Button`).

## Свойства

| Свойство    | Описание                                            | Типизация                                  | По умолчанию |
| ----------- | --------------------------------------------------- | ------------------------------------------ | ------------ |
| `items`     | пункты меню                                         | `ExtraMenuItem[]`                          | `[]`         |
| `popup`     | режим всплывающего меню                             | `boolean`                                  | `false`      |
| `open`      | видимость всплывающего меню (управляемое состояние) | `boolean`                                  | `false`      |
| `appendTo`  | контейнер рендера всплывающего меню                 | `'body' \| 'self' \| ExtraMenuElementLike` | `'body'`     |
| `ariaLabel` | метка для программ экранного доступа                | `string`                                   | —            |

- Пункт выбирается нажатием по строке целиком, а не только по тексту или иконке.
- Заголовок группы не фокусируется и не выбирается.
- Разделитель исключён из клавиатурной навигации и подсчёта пунктов.
- Во всплывающем режиме меню отсутствует в DOM, пока его не открыли (`toggle()`/`show()` или `open`).

## События

| Событие      | Описание                                   | Типизация                                   |
| ------------ | ------------------------------------------ | ------------------------------------------- |
| `itemSelect` | срабатывает при выборе пункта              | `(event: ExtraMenuItemSelectEvent) => void` |
| `show`       | срабатывает при открытии всплывающего меню | `() => void`                                |
| `hide`       | срабатывает при закрытии всплывающего меню | `() => void`                                |

## Методы

| Метод    | Описание                     | Типизация                                |
| -------- | ---------------------------- | ---------------------------------------- |
| `toggle` | переключить всплывающее меню | `(anchor?: ExtraMenuAnchorLike) => void` |
| `show`   | открыть всплывающее меню     | `(anchor?: ExtraMenuAnchorLike) => void` |
| `hide`   | закрыть всплывающее меню     | `() => void`                             |

`ExtraMenuAnchorLike` — элемент, ref или координаты, относительно которых позиционируется меню.
В вебе допускается передача `Event` — якорь вычисляется из `event.currentTarget`.
`ExtraMenuElementLike` — элемент или ref на него.

## Слоты

| Слот      | Описание                                                                           | Контекст          |
| --------- | ---------------------------------------------------------------------------------- | ----------------- |
| `itemEnd` | произвольное содержимое в конце пункта — после текста и `caption`, перед `iconEnd` | `ExtraMenuAction` |

Слот дополняет штатный пункт, а не заменяет его: текст, `caption`, иконки, выбор и навигацию
по-прежнему обеспечивает компонент. Подходит для хоткея и вспомогательного содержимого:
`Typography.Caption`, `Badge`, `Tag`. Диалоги, таблицы и карточки — нельзя.

## ExtraMenuItem

Пункт меню — размеченное объединение трёх сущностей.

```ts
type ExtraMenuItem = ExtraMenuAction | ExtraMenuGroup | ExtraMenuSeparator;
```

### ExtraMenuAction

| Свойство   | Описание                                                                                     | Типизация                                   |
| ---------- | -------------------------------------------------------------------------------------------- | ------------------------------------------- |
| `label`    | текст пункта                                                                                 | `string`                                    |
| `caption`  | подпись под текстом пункта                                                                   | `string`                                    |
| `icon`     | класс иконки tabler icon перед текстом                                                       | `string`                                    |
| `iconEnd`  | класс иконки tabler icon после текста                                                        | `string`                                    |
| `selected` | пункт отмечен как текущий (активный раздел)                                                  | `boolean`                                   |
| `visible`  | пункт отображается                                                                           | `boolean`                                   |
| `href`     | адрес перехода (атрибут `href`); без него переход делает приложение в `command`/`itemSelect` | `string`                                    |
| `target`   | где открыть `href` (атрибут `target`): `_self` — в текущей вкладке, `_blank` — в новой       | `string`                                    |
| `command`  | обработчик выбора пункта; вызывается перед `itemSelect`                                      | `(event: ExtraMenuItemSelectEvent) => void` |
| `id`       | идентификатор пункта                                                                         | `string`                                    |

`icon` и `iconEnd` принимают CSS-класс tabler целиком (`"ti ti-x"`); пустая строка — иконки нет.
`caption` — одна строка пояснения, без точки в конце.

### ExtraMenuGroup

| Свойство  | Описание             | Типизация                                   |
| --------- | -------------------- | ------------------------------------------- |
| `label`   | заголовок группы     | `string`                                    |
| `items`   | пункты группы        | `(ExtraMenuAction \| ExtraMenuSeparator)[]` |
| `visible` | группа отображается  | `boolean`                                   |
| `id`      | идентификатор группы | `string`                                    |

Вложенность ограничена одним уровнем: группа содержит только пункты и разделители.

### ExtraMenuSeparator

| Свойство    | Описание                   | Типизация |
| ----------- | -------------------------- | --------- |
| `separator` | разделитель между пунктами | `true`    |

## ExtraMenuItemSelectEvent

| Свойство        | Описание         | Типизация         |
| --------------- | ---------------- | ----------------- |
| `item`          | выбранный пункт  | `ExtraMenuAction` |
| `originalEvent` | исходное событие | `Event`           |
