# ExtraPopover

> ✅ **Реализован**: `ExtraPopoverComponent` (`@cdek-it/angular-ui-kit`) соответствует спецификации.

Плавающий контейнер, появляющийся по клику на целевой элемент.

| Свойство      | Описание                                | Типизация                                 | По умолчанию |
| ------------- | --------------------------------------- | ----------------------------------------- | ------------ |
| `appendTo`    | куда крепить оверлей                    | `HTMLElement \| 'body' \| 'self' \| null` | `'body'`     |
| `autoZIndex`  | автоматическое управление z-index       | `boolean`                                 | `true`       |
| `baseZIndex`  | базовое значение z-index                | `number`                                  | `0`          |
| `dismissable` | закрывать по клику вне панели           | `boolean`                                 | `true`       |
| `focusOnShow` | переводить фокус на панель при открытии | `boolean`                                 | `true`       |

# Слоты (content projection)

| Слот      | Описание            |
| --------- | ------------------- |
| `content` | содержимое поповера |

# События

| Событие | Описание                 | Типизация    |
| ------- | ------------------------ | ------------ |
| `show`  | срабатывает при открытии | `() => void` |
| `hide`  | срабатывает при закрытии | `() => void` |
