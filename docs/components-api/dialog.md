# ExtraDialog

> ✅ **Реализован**: `ExtraDialogComponent` (`@cdek-it/angular-ui-kit`) соответствует спецификации.

Универсальное окно (модальное или немодальное) для отображения произвольного содержимого.

| Свойство           | Описание                                     | Типизация                    |
| ------------------ | -------------------------------------------- | ---------------------------- |
| `show-overlay`     | отображать маску (overlay) поверх интерфейса | `boolean`                    |
| `show-maximize`    | кнопка разворота окна на весь экран          | `boolean`                    |
| `show-close`       | кнопка закрытия окна                         | `boolean`                    |
| `header`           | заголовок окна (строкой)                     | `string`                     |
| `visible`          | видимость окна                               | `boolean`                    |
| `size`             | размер окна                                  | `sm \| default \| lg \| xlg` |
| `dismissable-mask` | закрывать окно при клике на маску            | `boolean`                    |
| `close-on-escape`  | закрывать окно по нажатию Escape             | `boolean`                    |
| `focus-on-show`    | фокус на первый элемент при открытии         | `boolean`                    |
| `append-to`        | элемент, к которому монтируется окно         | `string`                     |

# Слоты (content projection)

| Слот      | Описание                                         |
| --------- | ------------------------------------------------ |
| `header`  | содержимое верхнего колонтитула (заголовок)      |
| `content` | основное содержимое окна (тело)                  |
| `footer`  | содержимое нижнего колонтитула (кнопки/действия) |

# События

| Событие      | Описание                               | Типизация    |
| ------------ | -------------------------------------- | ------------ |
| `onShow`     | срабатывает при открытии окна          | `() => void` |
| `onHide`     | срабатывает при закрытии окна          | `() => void` |
| `onMaximize` | срабатывает при развороте/сворачивании | `() => void` |
