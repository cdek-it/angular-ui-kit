# ExtraDialog

> ✅ **Реализован**: `ExtraDialogComponent` (`@cdek-it/angular-ui-kit`) соответствует спецификации.

Универсальное окно (модальное или немодальное) для отображения произвольного содержимого.

| Свойство           | Описание                                     | Типизация                    |
| ------------------ | -------------------------------------------- | ---------------------------- |
| `showOverlay`      | отображать маску (overlay) поверх интерфейса | `boolean`                          |
| `showMaximize`     | кнопка разворота окна на весь экран          | `boolean`                          |
| `showClose`        | кнопка закрытия окна                         | `boolean`                          |
| `header`           | заголовок окна (строкой)                     | `string`                           |
| `visible`          | видимость окна                               | `boolean`                          |
| `size`             | размер окна                                  | `small \| base \| large \| xlarge` |
| `dismissableMask`  | закрывать окно при клике на маску            | `boolean`                          |
| `closeOnEscape`    | закрывать окно по нажатию Escape             | `boolean`                          |
| `focusOnShow`      | фокус на первый элемент при открытии         | `boolean`                          |
| `appendTo`         | элемент, к которому монтируется окно         | `string`                           |

# Слоты (content projection)

| Слот      | Описание                                         |
| --------- | ------------------------------------------------ |
| `header`  | содержимое верхнего колонтитула (заголовок)      |
| `content` | основное содержимое окна (тело)                  |
| `footer`  | содержимое нижнего колонтитула (кнопки/действия) |

# События

| Событие      | Описание                               | Типизация    |
| ------------ | -------------------------------------- | ------------ |
| `show`     | срабатывает при открытии окна          | `() => void` |
| `hide`     | срабатывает при закрытии окна          | `() => void` |
| `maximize` | срабатывает при развороте/сворачивании | `() => void` |
