# ExtraDialog

Универсальное окно (модальное или немодальное) для отображения произвольного содержимого.

| Свойство       | Описание                                    | Типизация  |
| -------------- | ------------------------------------------- | ---------- |
| `modal`        | отображать маску (overlay) поверх интерфейса | `boolean`  |
| `maximizable`  | кнопка разворота окна на весь экран         | `boolean`  |
| `show-close`   | кнопка закрытия окна                        | `boolean`  |

# Слоты (content projection)

| Слот      | Описание                                |
| --------- | --------------------------------------- |
| `header`  | содержимое верхнего колонтитула (заголовок) |
| `content` | основное содержимое окна (тело)         |
| `footer`  | содержимое нижнего колонтитула (кнопки/действия) |

# События

| Событие      | Описание                              | Типизация  |
| ------------ | ------------------------------------- | ---------- |
| `onShow`     | срабатывает при открытии окна         | `() => void` |
| `onHide`     | срабатывает при закрытии окна         | `() => void` |
| `onMaximize` | срабатывает при развороте/сворачивании | `() => void` |
