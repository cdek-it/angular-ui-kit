# ExtraDialog

> ✅ **Реализован**: `ExtraDialogComponent` (`@cdek-it/angular-ui-kit`) соответствует спецификации.

Универсальное окно (модальное или немодальное) для отображения произвольного содержимого.

| Свойство          | Описание                                     | Типизация                          | По умолчанию |
| ----------------- | -------------------------------------------- | ---------------------------------- | ------------ |
| `showOverlay`     | отображать маску (overlay) поверх интерфейса | `boolean`                          | `true`       |
| `showMaximize`    | кнопка разворота окна на весь экран          | `boolean`                          | `false`      |
| `showClose`       | кнопка закрытия окна                         | `boolean`                          | `true`       |
| `header`          | заголовок окна (строкой)                     | `string`                           | `''`         |
| `visible`         | видимость окна                               | `boolean`                          | `false`      |
| `size`            | размер окна                                  | `small \| base \| large \| xlarge` | `base`       |
| `dismissableMask` | закрывать окно при клике на маску            | `boolean`                          | `false`      |
| `closeOnEscape`   | закрывать окно по нажатию Escape             | `boolean`                          | `true`       |
| `focusOnShow`     | фокус на первый элемент при открытии         | `boolean`                          | `false`      |
| `appendTo`        | элемент, к которому монтируется окно         | `string`                           | `'body'`     |

# Слоты (content projection)

| Слот      | Описание                                         |
| --------- | ------------------------------------------------ |
| `header`  | содержимое верхнего колонтитула (заголовок)      |
| `content` | основное содержимое окна (тело)                  |
| `footer`  | содержимое нижнего колонтитула (кнопки/действия) |

# События

| Событие    | Описание                               | Типизация    |
| ---------- | -------------------------------------- | ------------ |
| `show`     | срабатывает при открытии окна          | `() => void` |
| `hide`     | срабатывает при закрытии окна          | `() => void` |
| `maximize` | срабатывает при развороте/сворачивании | `() => void` |
