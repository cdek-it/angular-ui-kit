# ExtraMessage

> ✅ **Реализован**: `ExtraMessageComponent` (`@cdek-it/angular-ui-kit`) соответствует спецификации.

Сообщение-уведомление.

| Свойство    | Описание                                                                                    | Типизация                              | По умолчанию             |
| ----------- | ------------------------------------------------------------------------------------------- | -------------------------------------- | ------------------------ |
| `severity`  | тип сообщения                                                                               | `info \| success \| warning \| danger` | `info`                   |
| `timer`     | таймер автоскрытия                                                                          | `boolean`                              | `false`                  |
| `message`   | заголовок сообщения                                                                         | `string`                               | `''`                     |
| `caption`   | пояснение сообщения                                                                         | `string`                               | `''`                     |
| `icon`      | класс иконки tabler icon (вместо стандартной для `severity`); пустая строка скрывает иконку | `string`                               | — (иконка по `severity`) |
| `showClose` | кнопка закрытия                                                                             | `boolean`                              | `false`                  |
| `size`      | ширина сообщения                                                                            | `small \| base \| large \| xlarge`     | `base`                   |
| `fluid`     | растягивает сообщение на всю ширину контейнера                                              | `boolean`                              | `false`                  |

# Слоты (content projection)

| Слот      | Описание              |
| --------- | --------------------- |
| `content` | контент после caption |
| `footer`  | контент футера        |

# События

| Событие | Описание                           | Типизация    |
| ------- | ---------------------------------- | ------------ |
| `close` | срабатывает при закрытии сообщения | `() => void` |
