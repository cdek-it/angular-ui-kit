# ExtraDrawer

Панель, выезжающая с края экрана.

| Свойство       | Описание                                       | Типизация                    |
| -------------- | ---------------------------------------------- | ---------------------------- |
| `modal`        | отображать маску (overlay) поверх интерфейса   | `boolean`                    |
| `position`     | расположение панели                            | `left \| right \| top \| bottom` |
| `show-header`  | отображать верхний колонтитул (шапку можно скрыть) | `boolean`                |
| `show-back`    | кнопка «Назад» в шапке                         | `boolean`                    |

# Слоты (content projection)

| Слот      | Описание                                |
| --------- | --------------------------------------- |
| `header`  | содержимое верхнего колонтитула (заголовок) |
| `content` | основное содержимое панели (тело)       |
| `footer`  | содержимое нижнего колонтитула (кнопки/действия) |

# События

| Событие  | Описание                          | Типизация  |
| -------- | --------------------------------- | ---------- |
| `onShow` | срабатывает при открытии панели   | `() => void` |
| `onHide` | срабатывает при закрытии панели   | `() => void` |
