# ExtraBreadcrumb

> ✅ **Реализован**: `ExtraBreadcrumbComponent` (`@cdek-it/angular-ui-kit`) соответствует спецификации.

Навигационная цепочка («хлебные крошки»): путь от корня раздела до текущей страницы — цепочка
ссылок с разделителями, по которым можно вернуться наверх по иерархии. Не заменяет основную
навигацию (меню).

| Свойство        | Описание                                                                    | Типизация               | По умолчанию             |
| --------------- | --------------------------------------------------------------------------- | ----------------------- | ------------------------ |
| `items`         | элементы цепочки; последний элемент — текущая страница                      | `ExtraBreadcrumbItem[]` | `[]`                     |
| `showHome`      | показывать домашний элемент в начале цепочки                                | `boolean`               | `true`                   |
| `home`          | домашний элемент: ссылка на корень раздела                                  | `ExtraBreadcrumbItem`   | `{ icon: 'ti ti-home' }` |
| `homeAriaLabel` | метка домашнего элемента для программ экранного доступа (у него нет текста) | `string`                | —                        |
| `ariaLabel`     | метка для программ экранного доступа                                        | `string`                | —                        |

- Домашний элемент отображается только иконкой, без подписи и без разделителя перед ним. Он задаётся
  отдельно от `items`, а не первым элементом цепочки. Текста у него нет, поэтому при `showHome=true`
  приложение задаёт `homeAriaLabel` — иначе у ссылки нет доступного имени.
- Между элементами автоматически выводится разделитель (шеврон); он не интерактивен.
- Последний элемент — текущая страница: получает `aria-current="page"`, отображается приглушённым
  и не является ссылкой (не фокусируется, не выбирается).
- Схлопывания длинной цепочки нет (ни «…», ни выпадающего списка скрытых уровней, ни ограничения
  числа элементов): цепочка переносится на следующую строку.

# События

| Событие      | Описание                        | Типизация                                         |
| ------------ | ------------------------------- | ------------------------------------------------- |
| `itemSelect` | срабатывает при выборе элемента | `(event: ExtraBreadcrumbItemSelectEvent) => void` |

Для текущей страницы и элементов с `disabled` событие не срабатывает.

# Слоты (content projection)

| Слот   | Описание                                                                                                                    | Контекст              |
| ------ | --------------------------------------------------------------------------------------------------------------------------- | --------------------- |
| `item` | кастомное содержимое элемента цепочки (иконка и подпись); ссылку, выбор и `aria-current` по-прежнему обеспечивает компонент | `ExtraBreadcrumbItem` |

# ExtraBreadcrumbItem

| Свойство   | Описание                                                                                                        | Типизация                                         |
| ---------- | --------------------------------------------------------------------------------------------------------------- | ------------------------------------------------- |
| `label`    | текст элемента                                                                                                  | `string`                                          |
| `icon`     | класс иконки tabler icon                                                                                        | `string`                                          |
| `disabled` | элемент заблокирован                                                                                            | `boolean`                                         |
| `href`     | адрес перехода (атрибут `href`); без него переход делает приложение в `command`/`itemSelect`                    | `string`                                          |
| `target`   | где открыть `href` (атрибут `target`): `_self` — в текущей вкладке, `_blank` — в новой; без `href` не действует | `string`                                          |
| `command`  | обработчик выбора элемента                                                                                      | `(event: ExtraBreadcrumbItemSelectEvent) => void` |
| `id`       | идентификатор элемента                                                                                          | `string`                                          |

Пустая строка в `label`/`icon` — элемента нет. Элемент цепочки без `label` не используется: без
текста он нечитаем (иконкой без подписи отображается только домашний элемент).

# ExtraBreadcrumbItemSelectEvent

| Свойство        | Описание          | Типизация             |
| --------------- | ----------------- | --------------------- |
| `item`          | выбранный элемент | `ExtraBreadcrumbItem` |
| `originalEvent` | исходное событие  | `Event`               |
