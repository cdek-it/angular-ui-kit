# ExtraMegaMenu

> ✅ **Реализован**: `ExtraMegaMenuComponent` (`@cdek-it/angular-ui-kit`) соответствует спецификации.

Многоуровневая навигация: пункты верхнего уровня раскрывают панель с колонками, в колонках —
группы пунктов со своими заголовками. Подходит для крупных разделов с вложенной структурой.

Не используется для переключения представлений внутри страницы (`Tabs`), для пути к текущей
странице (`Breadcrumb`) и для небольшого одноуровневого меню без колонок (`Menu`, `Menubar`).

## Свойства

| Свойство         | Описание                                                                                                                                           | Типизация                | По умолчанию |
| ---------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------ | ------------ |
| `items`          | пункты верхнего уровня                                                                                                                             | `ExtraMegaMenuItem[]`    | `[]`         |
| `orientation`    | раскладка пунктов: `horizontal` — строка в шапке, `vertical` — список в боковой панели                                                             | `horizontal \| vertical` | `horizontal` |
| `breakpoint`     | ширина экрана, ниже которой меню сворачивается в мобильную кнопку (CSS-значение)                                                                   | `string`                 | `'960px'`    |
| `scrollHeight`   | максимальная высота списка пунктов (корневого и списков в панели); при превышении появляется прокрутка (CSS-значение). Не задано — без ограничения | `string`                 | —            |
| `ariaLabel`      | метка для программ экранного доступа                                                                                                               | `string`                 | —            |
| `ariaLabelledBy` | `id` внешнего элемента-метки для доступности                                                                                                       | `string`                 | —            |
| `tabindex`       | порядок перехода по Tab                                                                                                                            | `number`                 | `0`          |

- Пункт верхнего уровня с `items` раскрывает панель по нажатию или наведению; стрелка подменю —
  часть пункта, а не отдельная кнопка. Пока панель открыта, пункт отображается активным и получает
  `aria-expanded="true"`.
- `horizontal`: панель раскрывается вниз на всю ширину контейнера, колонки — сетка на 12 долей.
  `vertical`: панель выезжает вбок от пункта.
- Ниже `breakpoint` остаётся только мобильная кнопка (в Figma — `orientation=none`), колонки панели
  схлопываются в один столбец.
- Заголовок группы не фокусируется и не выбирается.

## События

| Событие      | Описание                      | Типизация                                       |
| ------------ | ----------------------------- | ----------------------------------------------- |
| `itemSelect` | срабатывает при выборе пункта | `(event: ExtraMegaMenuItemSelectEvent) => void` |

У пункта верхнего уровня с `items` событие не срабатывает: он только раскрывает панель.

## Слоты

| Слот      | Описание                                                                                  | Контекст              |
| --------- | ----------------------------------------------------------------------------------------- | --------------------- |
| `itemEnd` | произвольное содержимое в конце пункта панели — после текста и `caption`, перед `iconEnd` | `ExtraMegaMenuAction` |

Слот дополняет штатный пункт, а не заменяет его: текст, `caption`, иконки, выбор и навигацию
по-прежнему обеспечивает компонент. Весь пункт — одна ссылка, поэтому в слот кладётся
неинтерактивное содержимое: `Typography.Caption`, `Badge`, `Tag`. Диалоги, таблицы и карточки — нельзя.
У пунктов верхнего уровня слота нет.

## ExtraMegaMenuItem

Пункт верхнего уровня — размеченное объединение.

```ts
type ExtraMegaMenuItem = ExtraMegaMenuRootItem | ExtraMegaMenuSeparator;
```

### ExtraMegaMenuRootItem

| Свойство  | Описание                                                                                     | Типизация                                       |
| --------- | -------------------------------------------------------------------------------------------- | ----------------------------------------------- |
| `label`   | текст пункта                                                                                 | `string`                                        |
| `icon`    | класс иконки tabler icon перед текстом                                                       | `string`                                        |
| `items`   | колонки раскрывающейся панели; без них пункт — простая ссылка                                | `ExtraMegaMenuColumn[]`                         |
| `visible` | пункт отображается                                                                           | `boolean`                                       |
| `href`    | адрес перехода (атрибут `href`); без него переход делает приложение в `command`/`itemSelect` | `string`                                        |
| `target`  | где открыть `href` (атрибут `target`): `_self` — в текущей вкладке, `_blank` — в новой       | `string`                                        |
| `command` | обработчик выбора пункта                                                                     | `(event: ExtraMegaMenuItemSelectEvent) => void` |
| `id`      | идентификатор пункта                                                                         | `string`                                        |

Стрелка подменю у пункта с `items` выводится автоматически.

### ExtraMegaMenuColumn

Колонка панели — список групп.

```ts
type ExtraMegaMenuColumn = ExtraMegaMenuGroup[];
```

### ExtraMegaMenuGroup

| Свойство  | Описание             | Типизация                                           |
| --------- | -------------------- | --------------------------------------------------- |
| `label`   | заголовок группы     | `string`                                            |
| `items`   | пункты группы        | `(ExtraMegaMenuAction \| ExtraMegaMenuSeparator)[]` |
| `visible` | группа отображается  | `boolean`                                           |
| `id`      | идентификатор группы | `string`                                            |

### ExtraMegaMenuAction

Пункт внутри панели.

| Свойство   | Описание                                                                                     | Типизация                                       |
| ---------- | -------------------------------------------------------------------------------------------- | ----------------------------------------------- |
| `label`    | текст пункта                                                                                 | `string`                                        |
| `caption`  | подпись под текстом пункта                                                                   | `string`                                        |
| `icon`     | класс иконки tabler icon перед текстом                                                       | `string`                                        |
| `iconEnd`  | класс иконки tabler icon после текста                                                        | `string`                                        |
| `selected` | пункт отмечен как выбранный                                                                  | `boolean`                                       |
| `visible`  | пункт отображается                                                                           | `boolean`                                       |
| `href`     | адрес перехода (атрибут `href`); без него переход делает приложение в `command`/`itemSelect` | `string`                                        |
| `target`   | где открыть `href` (атрибут `target`): `_self` — в текущей вкладке, `_blank` — в новой       | `string`                                        |
| `command`  | обработчик выбора пункта                                                                     | `(event: ExtraMegaMenuItemSelectEvent) => void` |
| `id`       | идентификатор пункта                                                                         | `string`                                        |

`icon` и `iconEnd` принимают CSS-класс tabler целиком (`"ti ti-x"`); пустая строка — иконки нет.
`caption` дополняет `label` новой информацией и не повторяет его.

### ExtraMegaMenuSeparator

| Свойство    | Описание                   | Типизация |
| ----------- | -------------------------- | --------- |
| `separator` | разделитель между пунктами | `true`    |

## ExtraMegaMenuItemSelectEvent

| Свойство        | Описание         | Типизация                                      |
| --------------- | ---------------- | ---------------------------------------------- |
| `item`          | выбранный пункт  | `ExtraMegaMenuRootItem \| ExtraMegaMenuAction` |
| `originalEvent` | исходное событие | `Event`                                        |
