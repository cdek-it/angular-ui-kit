# ExtraProgressBar

> ✅ **Реализован**: `ExtraProgressBarComponent` (`@cdek-it/angular-ui-kit`) соответствует спецификации.

Индикатор выполнения процесса.

| Свойство    | Описание                                                                | Типизация                      |
| ----------- | ----------------------------------------------------------------------- | ------------------------------ |
| `value`     | значение прогресса (0–100)                                              | `number`                       |
| `showValue` | отображать значение прогресса                                           | `boolean`                      |
| `mode`      | режим отображения: с известным процентом или анимированный без значения | `determinate \| indeterminate` |
