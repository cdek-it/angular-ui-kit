# ExtraRating

| Свойство    | Описание                                       | Типизация  |
| ----------- | ---------------------------------------------- | ---------- |
| `stars`     | количество звёзд                               | `number`   |
| `paddings`  | отступы вокруг звёзд (увеличенная область нажатия) | `boolean` |
| `clearable` | отображать кнопку сброса оценки                | `boolean`  |

# События

| Событие  | Описание                            | Типизация                                |
| -------- | ----------------------------------- | ---------------------------------------- |
| `onRate` | срабатывает при выставлении оценки  | `(event: ExtraRatingRateEvent) => void`  |

# ExtraRatingRateEvent

| Свойство        | Описание          | Типизация |
| --------------- | ----------------- | --------- |
| `value`         | выставленная оценка | `number` |
| `originalEvent` | исходное событие  | `Event`   |
