# ExtraRating

> ✅ **Реализован**: `ExtraRatingComponent` (`@cdek-it/angular-ui-kit`) соответствует спецификации.

| Свойство    | Описание                                                  | Типизация |
| ----------- | --------------------------------------------------------- | --------- |
| `stars`     | количество звёзд                                          | `number`  |
| `clearable` | отображать кнопку сброса оценки                           | `boolean` |
| `readonly`  | режим только для чтения — без возможности изменить оценку | `boolean` |
| `autofocus` | автофокус при монтировании компонента                     | `boolean` |

# События

| Событие | Описание                           | Типизация                               |
| ------- | ---------------------------------- | --------------------------------------- |
| `rate`  | срабатывает при выставлении оценки | `(event: ExtraRatingRateEvent) => void` |

# ExtraRatingRateEvent

| Свойство        | Описание            | Типизация |
| --------------- | ------------------- | --------- |
| `value`         | выставленная оценка | `number`  |
| `originalEvent` | исходное событие    | `Event`   |
