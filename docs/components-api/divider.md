# ExtraDivider

> ✅ **Реализован**: `ExtraDividerComponent` (`@cdek-it/angular-ui-kit`) соответствует спецификации.

Визуальный разделитель контента.

| Свойство | Описание                                                                                   | Типизация                                  | По умолчанию |
| -------- | ------------------------------------------------------------------------------------------ | ------------------------------------------ | ------------ |
| `layout` | ориентация разделителя                                                                     | `horizontal \| vertical`                   | `horizontal` |
| `type`   | стиль линии                                                                                | `solid \| dash`                            | `solid`      |
| `align`  | расположение контента относительно линии (`top`/`bottom` — только для `layout="vertical"`) | `left \| center \| right \| top \| bottom` | `center`     |

# Слоты (content projection)

| Слот      | Описание                                   |
| --------- | ------------------------------------------ |
| `content` | содержимое поверх линии (текст или иконка) |
