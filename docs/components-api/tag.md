# ExtraTag

> ✅ **Реализован**: `ExtraTagComponent` (`@cdek-it/angular-ui-kit`) соответствует спецификации.

Маркер для элементов интерфейса.

| Свойство   | Описание                 | Типизация                                                      | По умолчанию |
| ---------- | ------------------------ | -------------------------------------------------------------- | ------------ |
| `severity` | вариант стиля            | `primary \| secondary \| info \| success \| warning \| danger` | `primary`    |
| `value`    | текст тега               | `string`                                                       | `''`         |
| `rounded`  | полное скругление углов  | `boolean`                                                      | `false`      |
| `icon`     | класс иконки tabler icon | `string`                                                       | `''`         |
