# ExtraBadge

Счётчик или статус для элемента.

| Свойство    | Описание                                   | Типизация                              |
| ----------- | ------------------------------------------ | -------------------------------------- |
| `severity`  | вариант стиля                              | `primary \| info \| success \| warning \| danger` |
| `value`     | значение (счётчик/текст)                   | `string`                               |
| `dot`       | режим точки (без значения)                 | `boolean`                              |
| `size`      | размер                                     | `base \| large \| xlarge`              |
