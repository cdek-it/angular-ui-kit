# ExtraInputOtp

> ✅ **Реализован**: `ExtraInputOtpComponent` (`@cdek-it/angular-ui-kit`) соответствует спецификации.

| Свойство         | Описание                                                                      | Типизация                | По умолчанию |
| ---------------- | ----------------------------------------------------------------------------- | ------------------------ | ------------ |
| `length`         | количество полей ввода                                                        | `number`                 | `4`          |
| `mask`           | скрывать введённое значение (как пароль)                                      | `boolean`                | `false`      |
| `integerOnly`    | допускать только цифры                                                        | `boolean`                | `false`      |
| `autofocus`      | автофокус на первой ячейке при инициализации                                  | `boolean`                | `false`      |
| `size`           | размер ячейки                                                                 | `small \| base \| large` | `base`       |
| `readonly`       | только для чтения                                                             | `boolean`                | `false`      |
| `required`       | поле обязательно для заполнения                                               | `boolean`                | `false`      |
| `name`           | имя поля (нативный атрибут `name`); используется браузером для автозаполнения | `string`                 | —            |
| `autocomplete`   | значение нативного атрибута `autocomplete`                                    | `string`                 | —            |
| `ariaLabel`      | метка для программ экранного доступа                                          | `string`                 | —            |
| `ariaLabelledBy` | `id` внешнего элемента-метки для доступности                                  | `string`                 | —            |
| `tabindex`       | порядок перехода по Tab                                                       | `number`                 | —            |

| Событие    | Описание                       | Типизация                                   |

# ExtraInputOtpChangeEvent

Событие изменения кода, передаётся в `onChange`.

| Свойство        | Описание         | Типизация |
| --------------- | ---------------- | --------- |
| `value`         | введённый код    | `string`  |
| `originalEvent` | исходное событие | `Event`   |

## Формы и поведение

Модель — `string | null`. Работают FormControl, formControlName и ngModel. Внешние изменения не вызывают onChange. Вставка обрезается до length и вызывает одно событие; integerOnly проверяет все символы. Disabled и readonly запрещают изменение, autofocus применяется только к доступной первой ячейке. Blur отмечает форму touched; invalid отображается после touched либо dirty.

`required` использует Validators.required: непустая частичная строка валидна. Для проверки полной длины кода добавьте собственный валидатор формы. Доступное имя каждой ячейки по умолчанию — «Одноразовый код», его можно изменить через ariaLabel или ariaLabelledBy.

Размеры small/base/large — 28/36/40; расстояние между ячейками 8, шрифт 14/18. В Figma отрисована базовая ячейка 36; дополнительные размеры задаёт экспорт компонентных токенов.
