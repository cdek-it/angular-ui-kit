# ExtraInputOtp

> ✅ **Реализован**: `ExtraInputOtpComponent` (`@cdek-it/angular-ui-kit`) соответствует спецификации.

| Свойство         | Описание                                                                      | Типизация                | По умолчанию |
| ---------------- | ----------------------------------------------------------------------------- | ------------------------ | ------------ |
| `length`         | количество полей ввода                                                        | `number`                 | `4`          |
| `masked`         | скрывать введённое значение (как пароль)                                      | `boolean`                | `false`      |
| `integerOnly`    | допускать только цифры                                                        | `boolean`                | `false`      |
| `autofocus`      | автофокус на первой ячейке при инициализации                                  | `boolean`                | `false`      |
| `size`           | размер ячейки                                                                 | `small \| base \| large` | `base`       |
| `readonly`       | только для чтения                                                             | `boolean`                | `false`      |
| `required`       | поле обязательно для заполнения                                               | `boolean`                | `false`      |
| `name`           | имя поля (нативный атрибут `name`); используется браузером для автозаполнения | `string`                 | —            |
| `autocomplete`   | значение нативного атрибута `autocomplete`                                    | `string`                 | —            |
| `ariaLabel`      | метка для программ экранного доступа                                          | `string`                 | —            |
| `ariaLabelledBy` | `id` внешнего элемента-метки для доступности                                  | `string`                 | —            |
| `tabindex`       | порядок перехода по Tab                                                       | `number`                 | —            |

# Стекозависимые пропсы

| Описание      | Angular                                         | Vue          | React   | Типизация | По умолчанию |
| ------------- | ----------------------------------------------- | ------------ | ------- | --------- | ------------ |
| введённый код | `ngModel` \| `formControl` \| `formControlName` | `modelValue` | `value` | `string`  | `null`       |

# События

| Событие  | Описание                       | Типизация                                   |
| -------- | ------------------------------ | ------------------------------------------- |
| `change` | срабатывает при изменении кода | `(event: ExtraInputOtpChangeEvent) => void` |

# ExtraInputOtpChangeEvent

Событие изменения кода, передаётся в `change`.

| Свойство        | Описание         | Типизация |
| --------------- | ---------------- | --------- |
| `value`         | введённый код    | `string`  |
| `originalEvent` | исходное событие | `Event`   |
