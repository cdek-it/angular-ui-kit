# ExtraGalleria

Галерея для просмотра изображений.

| Свойство         | Описание                                      | Типизация             | По умолчанию |
| ---------------- | --------------------------------------------- | --------------------- | ------------ |
| `value`          | массив изображений                            | `ExtraGalleriaItem[]` | `[]`         |
| `fullScreen`     | полноэкранный режим (маска поверх интерфейса) | `boolean`             | `false`      |
| `showNavButtons` | стрелки навигации                             | `boolean`             | `false`      |
| `showIndicators` | точки-индикаторы (пагинация)                  | `boolean`             | `false`      |

# События

| Событие             | Описание                          | Типизация                 |
| ------------------- | --------------------------------- | ------------------------- |
| `activeIndexChange` | срабатывает при смене изображения | `(index: number) => void` |

# ExtraGalleriaItem

| Свойство    | Описание              | Типизация |
| ----------- | --------------------- | --------- |
| `image`     | основное изображение  | `string`  |
| `thumbnail` | миниатюра             | `string`  |
| `alt`       | alt-текст             | `string`  |
| `caption`   | подпись к изображению | `string`  |
