# ExtraGalleria

Галерея для просмотра изображений.

| Свойство          | Описание                                      | Типизация             |
| ----------------- | --------------------------------------------- | --------------------- |
| `value`           | массив изображений                            | `ExtraGalleriaItem[]` |
| `mask`            | полноэкранный режим (маска поверх интерфейса) | `boolean`             |
| `show-nav`        | стрелки навигации                             | `boolean`             |
| `show-indicators` | точки-индикаторы (пагинация)                  | `boolean`             |

# События

| Событие               | Описание                          | Типизация                 |
| --------------------- | --------------------------------- | ------------------------- |
| `onActiveIndexChange` | срабатывает при смене изображения | `(index: number) => void` |

# ExtraGalleriaItem

| Свойство    | Описание              | Типизация |
| ----------- | --------------------- | --------- |
| `image`     | основное изображение  | `string`  |
| `thumbnail` | миниатюра             | `string`  |
| `alt`       | alt-текст             | `string`  |
| `caption`   | подпись к изображению | `string`  |
