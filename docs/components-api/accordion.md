# ExtraAccordion

Контейнер из раскрывающихся панелей. Панели передаются как дочерние элементы `ExtraAccordionPanel`.

| Свойство    | Описание                                          | Типизация  |
| ----------- | ------------------------------------------------- | ---------- |
| `multiple`  | разрешить несколько раскрытых панелей одновременно | `boolean`  |

# События

| Событие   | Описание                         | Типизация  |
| --------- | -------------------------------- | ---------- |
| `onOpen`  | срабатывает при раскрытии панели | `() => void` |
| `onClose` | срабатывает при сворачивании панели | `() => void` |

# ExtraAccordionPanel

Отдельная панель аккордеона: заголовок + раскрываемое тело.

| Свойство    | Описание                | Типизация  |
| ----------- | ----------------------- | ---------- |
| `icon`      | класс иконки заголовка  | `string`   |
| `expanded`  | раскрыта ли панель      | `boolean`  |
| `disabled`  | панель недоступна       | `boolean`  |

# Слоты (content projection)

| Слот      | Описание                       |
| --------- | ------------------------------ |
| `header`  | заголовок панели               |
| `content` | содержимое панели (тело)       |
