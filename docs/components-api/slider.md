# ExtraSlider

> ✅ **Реализован**: `ExtraSliderComponent` (`@cdek-it/angular-ui-kit`) соответствует спецификации.

| Свойство         | Описание                                     | Типизация                | По умолчанию |
| ---------------- | -------------------------------------------- | ------------------------ | ------------ |
| `min`            | минимальное значение                         | `number`                 | `0`          |
| `max`            | максимальное значение                        | `number`                 | `100`        |
| `step`           | шаг изменения значения                       | `number`                 | —            |
| `range`          | режим выбора диапазона (двумя ползунками)    | `boolean`                | `false`      |
| `orientation`    | ориентация шкалы                             | `horizontal \| vertical` | `horizontal` |
| `animate`        | анимация прыжка бегунка при клике по шкале   | `boolean`                | `false`      |
| `ariaLabel`      | метка для программ экранного доступа         | `string`                 | —            |
| `ariaLabelledBy` | `id` внешнего элемента-метки для доступности | `string`                 | —            |
| `tabindex`       | порядок перехода по Tab                      | `number`                 | `0`          |
| `autofocus`      | автофокус при монтировании компонента        | `boolean`                | `false`      |
| `required`       | поле обязательно для заполнения              | `boolean`                | `false`      |

# Стекозависимые пропсы

| Описание                                                                    | Angular                                         | Vue          | React   | Типизация            | По умолчанию |
| --------------------------------------------------------------------------- | ----------------------------------------------- | ------------ | ------- | -------------------- | ------------ |
| значение (при `range` — массив из двух значений, по умолчанию `[min, max]`) | `ngModel` \| `formControl` \| `formControlName` | `modelValue` | `value` | `number \| number[]` | `0`          |

# События

| Событие    | Описание                                    | Типизация                                 |
| ---------- | ------------------------------------------- | ----------------------------------------- |
| `change`   | срабатывает при изменении значения          | `(event: ExtraSliderChangeEvent) => void` |
| `slideEnd` | срабатывает после завершения перетаскивания | `() => void`                              |

# ExtraSliderChangeEvent

| Свойство        | Описание                   | Типизация  |
| --------------- | -------------------------- | ---------- |
| `value`         | значение (одиночный режим) | `number`   |
| `values`        | значения (режим `range`)   | `number[]` |
| `originalEvent` | исходное событие           | `Event`    |
