# ExtraCard

Карточка для отображения информации.

| Свойство   | Описание                    | Типизация  |
| ---------- | --------------------------- | ---------- |
| `overlay`  | отображать тень (возвышение) | `boolean` |

# Слоты (content projection)

| Слот      | Описание                          |
| --------- | --------------------------------- |
| `header`  | верхняя область (обычно изображение) |
| `content` | тело карточки                     |
| `footer`  | нижний колонтитул                 |
