# ExtraSkeleton

> ✅ **Реализован**: `ExtraSkeletonComponent` (`@cdek-it/angular-ui-kit`) соответствует спецификации.

Плейсхолдер контента на момент загрузки.

| Свойство       | Описание                                                                    | Типизация             |
| -------------- | --------------------------------------------------------------------------- | --------------------- |
| `shape`        | форма                                                                       | `rectangle \| circle` |
| `animation`    | тип анимации: волновой шиммер или без анимации                              | `wave \| none`        |
| `width`        | ширина элемента (CSS-значение); игнорируется при заданном `size`            | `string`              |
| `height`       | высота элемента (CSS-значение); игнорируется при заданном `size`            | `string`              |
| `size`         | размер элемента, задаёт ширину и высоту одновременно (для `shape="circle"`) | `string \| undefined` |
| `borderRadius` | скругление углов (CSS-значение), переопределяет значение темы               | `string \| undefined` |
