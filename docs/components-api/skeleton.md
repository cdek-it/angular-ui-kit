# ExtraSkeleton

> ✅ **Реализован**: `ExtraSkeletonComponent` (`@cdek-it/angular-ui-kit`) соответствует спецификации.

Плейсхолдер контента на момент загрузки.

| Свойство       | Описание                                                                    | Типизация             | По умолчанию |
| -------------- | --------------------------------------------------------------------------- | --------------------- | ------------ |
| `shape`        | форма                                                                       | `rectangle \| circle` | `rectangle`  |
| `animation`    | тип анимации: волновой шиммер или без анимации                              | `wave \| none`        | `wave`       |
| `width`        | ширина элемента (CSS-значение); игнорируется при заданном `size`            | `string`              | `'100%'`     |
| `height`       | высота элемента (CSS-значение); игнорируется при заданном `size`            | `string`              | `'1rem'`     |
| `size`         | размер элемента, задаёт ширину и высоту одновременно (для `shape="circle"`) | `string`              | —            |
| `borderRadius` | скругление углов (CSS-значение), переопределяет значение темы               | `string`              | —            |
