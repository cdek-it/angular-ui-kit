# ExtraTimeline

Список событий в хронологическом порядке: ось с маркерами, соединительная линия, основной и
противоположный контент (дата/время). Компонент data-driven: события передаются массивом `value`,
рендер каждой стороны настраивается слотами.

## Свойства

| Свойство      | Описание                                                                    | Типизация                                            | По умолчанию |
| ------------- | --------------------------------------------------------------------------- | ---------------------------------------------------- | ------------ |
| `value`       | массив событий; каждый элемент доступен в слотах                            | `ExtraTimelineItem[]`                                | `[]`         |
| `layout`      | ориентация ленты                                                            | `vertical \| horizontal`                             | `vertical`   |
| `align`       | положение контента относительно маркера: `left`/`right` — при `vertical`, `top`/`bottom` — при `horizontal`, `opposite` — чередование сторон | `left \| right \| top \| bottom \| opposite` | `left`       |
| `showCaption` | показывать противоположную сторону (слот `opposite`)                        | `boolean`                                            | `true`       |
| `line`        | стиль соединительной линии                                                  | `solid \| dashed \| dotted \| none`                  | `solid`      |
| `icon`        | класс иконки tabler icon в маркере                                           | `string`                                             | `''`         |
| `markerColor` | цвет маркера (токен из справочника)                                         | `string`                                             | `''`         |

## Слоты (content projection)

| Слот      | Описание                                                        | Контекст  |
| --------- | --------------------------------------------------------------- | --------- |
| `content` | основной контент события; без слота — строковое значение        | `item`    |
| `opposite` | противоположная сторона (дата/время); рендерится при `showCaption` | `item`   |
| `marker`  | кастомный маркер; без слота — маркер по умолчанию с иконкой `icon` | `item` |

## ExtraTimelineItem

Компонент не навязывает форму события — поля читаются только в слотах. Рекомендуемая модель:

| Свойство  | Описание                    | Типизация | По умолчанию |
| --------- | --------------------------- | --------- | ------------ |
| `value`   | наименование события        | `string`  | —            |
| `caption` | пояснение (дата/время)      | `string`  | —            |
