# Правила контракта

Короткий свод. Обоснования, исследование отрасли и история решений — в
`naming-rules.md`.

## Регистр

camelCase везде: спека, Figma-property, контракт, код всех китов.
Vue сам покажет дефис в шаблоне — канон при этом не меняется.

## Булевы свойства

| Класс                | Форма        | Примеры                                                             |
| -------------------- | ------------ | ------------------------------------------------------------------- |
| Состояние            | без префикса | `disabled`, `loading`, `visible`, `expanded`, `checked`, `required` |
| Показ элемента       | `show*`      | `showClose`, `showOverlay`, `showIcon`, `showHeader`                |
| Возможность действия | `*able`      | `dismissable`, `resizable`, `sortable`                              |

Запрещено: `is*`, `has*`, `with*`, `no*`, `hide*` и любые отрицания.

## События

В каноне — без префикса `on`. Префикс добавляет генератор под кит.

| Канон   | Angular     | React, React Native | Vue      |
| ------- | ----------- | ------------------- | -------- |
| `show`  | `(onShow)`  | `onShow`            | `@show`  |
| `close` | `(onClose)` | `onClose`           | `@close` |

Форма: глагол — `show`, `hide`, `close`, `change`, `clear`, `select`.
Payload: `Extra<Component><Verb>Event` с полем `originalEvent`.

Если у компонента несколько независимых значений и голого `change` недостаточно, чтобы
понять, что именно изменилось — событие называется `<subject>Change`, где `<subject>` —
имя изменившегося значения: `pageChange` (значение — число), `activeIndexChange`,
`monthChange`/`yearChange`. Это применимо только когда полезная нагрузка события — не
булево значение.

Если изменившееся значение — булево (`checked`, `selected` и т.п.), суффикс `Change` не
добавляется: событие называется как само действие/состояние, глаголом или в форме булева
свойства, без слова `Change` — `selectAll`, а не `selectAllChange`. Ориентир: как назвали
бы аналогичное булево свойство (`show*`/`*able`/без префикса), так и называется событие,
без `Change` на конце.

## Слоты

`header` · `content` · `footer`. В Angular — одна директива на компонент:

    <ng-template extra<Component>Template="header">

## Иконки

`icon` — строка, CSS-класс tabler целиком: `"ti ti-x"`.
`iconPosition` — `left | right`.
Пустая строка означает отсутствие иконки. Значение `null` в наборе не пишется.

## Контентные свойства

| Имя           | Роль                           |
| ------------- | ------------------------------ |
| `label`       | основная подпись               |
| `message`     | заголовок сообщения            |
| `caption`     | пояснение под основным текстом |
| `placeholder` | подсказка в пустом поле        |
| `info`        | текст тултипа                  |

Не используются: `helpText`, `note`, `summary`, `detail`.

## Шкалы значений

| Свойство   | Значения                                                         |
| ---------- | ---------------------------------------------------------------- |
| `size`     | `small \| base \| large \| xlarge`                               |
| `severity` | `danger \| warning \| success \| info`                           |
| `variant`  | `primary \| secondary \| tertiary`, плюс `text \| link` где есть |

`severity` — смысловой статус, `variant` — уровень акцента. Не смешивать:
`primary` не бывает severity, `danger` не бывает variant.
Нейтрального `base` в `severity` нет.

## Позиции

Словарь: `top | bottom | left | right`. Логические `start` и `end` в новых
свойствах не используются.

| Компоненты                          | Свойство        | Значения        | Дефолт  |
| ----------------------------------- | --------------- | --------------- | ------- |
| поля ввода                          | `labelPosition` | `top \| left`   | `top`   |
| поля ввода                          | `floatLabel`    | `boolean`       | `false` |
| Checkbox, RadioButton, ToggleSwitch | `labelPosition` | `left \| right` | `right` |

Значение `default` не используется нигде: пишется явное `top` или `right`.

## Уникальность

Одно имя — один смысл и один тип во всей библиотеке. Синонимы запрещены.

| Принято                | Отвергнуто                          |
| ---------------------- | ----------------------------------- |
| `showTextInput`        | `showInputText`                     |
| `showNavButtons`       | `showButtonNav`                     |
| `showChips`            | `chips`                             |
| `icon` — только строка | `icon` как булево, стало `showIcon` |

## Значение «не задано»

В Figma у варианта всегда есть значение — пустого варианта не бывает. Поэтому
состояние «элемента нет» там сделано отдельным значением с именем `null`. Это
слово-заглушка макета, а не значение API.

Вариант `null` в Figma остаётся: технически иначе никак. **В спеку он не
выносится.** В таблице свойств пишутся только настоящие значения, а способ
получить «ничего» указывается строкой рядом.

    В Figma       iconPosition: null | prefix | postfix
    В спеке       iconPosition: left | right
                  иконки нет — оставьте icon пустым

Отсутствие значения выражается пустой строкой для текстовых свойств и
отсутствием атрибута для остальных.

Где это сейчас: `iconPosition` у пяти Button-компонентов и ToggleButton,
`variant` у `<DataTable.BodyCellBase>`.

## Узаконенные исключения

| Где                     | Что                                         | Почему                                     |
| ----------------------- | ------------------------------------------- | ------------------------------------------ |
| `<Badge>`, `<Tag>`      | `severity` включает `primary` и `secondary` | второй оси нет, цвет задаётся одной шкалой |
| `<MeterGroup>`          | `labelPosition: start \| end`               | оставлено как есть                         |
| `<Timeline.Item*>`      | `align: opposite \| …`                      | `opposite` — режим чередования, не позиция |
| `<Button.Danger>` и др. | `severity` выражен подкомпонентами          | решение принято, оставлено как есть        |
